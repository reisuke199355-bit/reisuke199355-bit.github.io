れいすけ

こんにちは、「れいすけ」です。

現在は、友達のゲーム制作を手伝いながら、Unityを使ったUI制作やシステム実装などをしています。

最近はAIを積極的に活用しており、ChatGPTやClaude Codeなどを使いながら開発を進めることが多いです。

ゲーム制作を通して学んだ知識や技術は、その場限りで終わらせず、自分自身の経験として残していきたいと思っています。

今後はMMDにも挑戦し、Fantiaなどで作品を公開できるようになることも目標の一つです。

このサイトについて

このサイトを作ったきっかけは、友達とのゲーム制作でした。

現在は週に数回、夜9時から0時までDiscordで通話をしながらゲーム制作を進めています。

制作は正直言ってストレスです、考え方や進め方の違いから意見がぶつかることも少なくありません。

そんな中で、自分の考えを整理したり、その時に感じたことを書き残したりする場所が欲しいと思い、日記を書き始めました。

最初は気持ちを整理するための場所でしたが、続けていくうちに「ゲーム制作」「AI」「日々の記録」など、自分が積み重ねてきたものをまとめる"ネット上の基地"として育てていきたいと思うようになりました。

このサイトは、自分が何を考え、何を作り、何を学んできたのかを記録していく場所です。

気が向いたときに、のんびり覗いてもらえたら嬉しいです。
