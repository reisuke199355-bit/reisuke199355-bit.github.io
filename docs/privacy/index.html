プライバシーポリシー

このページでは、「れいすけの日常の記録」（以下「当サイト」）における、訪問者の情報の取り扱いについて説明します。

当サイトが集めている情報

当サイトは、訪問者の情報を集めていません。

当サイトは、あらかじめ用意したHTMLファイルを表示するだけの静的なサイトです。2026年10月31日の時点で、次のものをいずれも使用していません。

  • アクセス解析（Googleアナリティクスなど）
  • 広告・アフィリエイト
  • Cookie（クッキー）
  • JavaScript
  • お問い合わせフォームなどの入力欄
  • 外部のサイトから読み込む画像・フォント・プログラム

そのため、当サイトを見ても閲覧者の端末に情報が保存されることはなく、運営者が誰かの閲覧履歴を知ることもできません。

サイトの置き場所について

当サイトは、GitHub, Inc. が提供する「GitHub Pages」というサービス上に置いています。

GitHubの説明によると、GitHub Pagesのサイトにアクセスすると、訪問者がGitHubにサインインしているかどうかに関係なく、訪問者のIPアドレスがセキュリティ上の目的で記録・保存されます。

これはGitHub社が自社のサービスを守るために行っているもので、当サイトの運営者が設定したものではありません。また、運営者がその記録を見ることもできません。詳しくは次のページをご覧ください。

  • GitHub Pages とは（「データ コレクション」の項）
  • GitHub プライバシーに関する声明

Cookieについて

当サイトは、Cookieを使用していません。閲覧者の端末にCookieを保存することはありません。

広告・アフィリエイトについて

当サイトには、広告もアフィリエイトリンクも掲載していません。Google AdSenseなどの第三者配信による広告サービスも利用していません。

今後これらを導入する場合は、導入する前にこのページを書き換えてお知らせします。

アクセス解析について

当サイトは、アクセス解析ツールを導入していません。訪問者の行動を記録するしくみは一切使用していません。

今後導入する場合は、このページを書き換えてお知らせします。

外部へのリンクについて

当サイトから、外部のサイトへリンクすることがあります。リンク先での情報の取り扱いについては、それぞれのサイトの方針をご確認ください。当サイトは、リンク先の内容について責任を負いません。

お問い合わせ

当サイトには、現在お問い合わせ用のフォームや連絡先を置いていません。連絡手段を設ける場合は、このページに追記します。

このページの変更について

当サイトの作りや、利用しているサービスが変わった場合は、このページの内容を書き換えます。
