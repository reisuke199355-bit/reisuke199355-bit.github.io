# Windows 用の追加 BAT

ここに置いてある BAT は、**このフォルダから `blog` の1つ上**
（`1_日記を取り込む.bat` などが並んでいる場所）へコピーして使います。

| ファイル | 役割 |
|---|---|
| `4_クラウドの投稿を受け取る.bat` | スマホから投稿して公開した日記を、手元のフォルダに取り込む |

## なぜ必要か

スマホから投稿してプルリクエストを取り込むと、**GitHub 側だけが新しく**なります。
その状態で `3_GitHubへ公開.bat` を実行すると、送信のときに
「先に取り込んでください」と断られます。

`4_クラウドの投稿を受け取る.bat` を先に実行しておけば、
これまでどおり `1` → `2` → `3` の手順で公開できます。

## コピーのしかた

1. このフォルダ（`blog/windows`）を開く
2. `4_クラウドの投稿を受け取る.bat` をコピー
3. `1_日記を取り込む.bat` が置いてあるフォルダに貼り付ける

BAT の中身は英数字だけで書いてあります（cmd.exe が日本語の BAT を
読み違えることがあるため）。画面に出る日本語は Python 側から出しています。

`goto` やカッコのブロックも使っていません。cmd.exe は改行が LF だけの
BAT でそれらを読み違えることがあるため、1行ずつの `if` だけで書いています。
（`.gitattributes` で `*.bat` は CRLF で配るようにもしていますが、
万一 LF になっても動くようにしてあります）

## 中でやっていること

```
python tools/sync.py
```

GitHub の最新を見て、**早送りできるときだけ**取り込みます。
手元に書きかけがあるときや、枝分かれしているときは、何もせずに知らせます。
