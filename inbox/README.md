# inbox（投稿の受け取り箱）

スマホや PC のブラウザから日記を投稿するときに、TXT をここへ置きます。
置かれた TXT は GitHub Actions が記事に変換し、プルリクエストを作ります。
**main には自動で入りません。** 取り込み（マージ）は人が手で行います。

## 置き方

```
inbox/2026-11-02.txt          ← カテゴリーは「日記」（既定）
inbox/感想/2026-11-02.txt     ← フォルダ名がカテゴリーになる
```

ファイル名には必ず日付を入れてください（日付が読めないものは記事になりません）。

GitHub の画面で名前を打つときの**区切りは `/`（スラッシュ）**です。
`\`（円記号）だと、そういう名前のファイルが1つできるだけで、
フォルダにはなりません。

## 中身の書き方

```
# きょうの題（1行目。省略すると「2026年11月2日」になります）
タグ: AI, 料理

ここから本文。
空行で段落が分かれます。
```

## 大事なこと

このリポジトリは**誰でも見られる公開リポジトリ**です。
ここに置いた文章は、**公開前でも第三者が読めます**。
公開してよいと決めた文章だけを置いてください。
書きかけの下書きは、スマホのメモアプリなど端末の中に置いてください。

くわしい手順は `MANUAL-cloud-posting.md` にあります。
